# Bundle Analysis Screenshots

Place your bundle visualizer screenshots here after running `npm run build` in each project.

## Required Files

| File | Description |
|------|-------------|
| `zustand-bundle.png` | Treemap from `stats.html` generated by `rollup-plugin-visualizer` in the zustand-version build. |
| `redux-toolkit-bundle.png` | Treemap from `stats.html` generated by `rollup-plugin-visualizer` in the redux-version build. |

## How to Capture

1. `cd zustand-version && npm run build`
2. Open the generated `zustand-version/stats.html` in your browser.
3. Screenshot the treemap and save as `zustand-bundle.png`.
4. Repeat for `redux-version` → save as `redux-toolkit-bundle.png`.

## Expected Sizes (approximate, gzipped)

| Library | Gzipped Size |
|---------|-------------|
| Context API | 0 KB (built into React) |
| zustand | ~3 KB |
